# Neovim config

This is my Neovim config, based heavially on `mini.nvim`.
A great deal of code was ~~stolen~~ borrowed from https://github.com/echasnovski/nvim/

## Requirements

- Neovim 0.12 or higher (absolute must, no working around this,
  I use `vim.pack` to handle plugin installaion, which was only
  introduced in Neovim 0.12)
- Ripgrep
- tree-sitter CLI
